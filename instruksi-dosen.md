# Tugas Pertemuan 6

## Materi: Git, npm, TypeScript, dan Vite

**Jenis Tugas:** Individu

### Deskripsi Tugas

Setiap mahasiswa diminta membuat **aplikasi web sederhana untuk mengelola daftar tugas kuliah** menggunakan TypeScript dan Vite.

Aplikasi wajib diunggah dan ditampilkan pada **website pribadi masing-masing mahasiswa** agar dapat diakses secara online.

### Ketentuan Tugas

**1. Membuat Aplikasi Web**

Aplikasi minimal memiliki fitur:

- Menampilkan daftar tugas kuliah.
- Menambahkan tugas baru.
- Mengedit dan menghapus tugas.
- Menampilkan status tugas (Belum Selesai / Selesai).
- Tampilan rapi dan responsif.

**2. Menggunakan Git dan GitHub**

- Membuat repository GitHub.
- Melakukan minimal 5 commit.
- Membuat minimal 2 branch.
- Melakukan merge branch ke branch utama.
- Mencoba menyelesaikan merge conflict.
- Melakukan push dan pull.
- Membuat minimal 1 Pull Request.
- Menggunakan file `.gitignore`.

**3. Menggunakan npm dan Vite**

- Membuat proyek menggunakan Vite.
- Menggunakan npm untuk mengelola package.
- Menggunakan `package.json` dan npm scripts.
- Memahami dependencies, devDependencies, dan semantic versioning.
- Menjalankan aplikasi dan melakukan build.

**4. Menggunakan TypeScript**

Dalam kode aplikasi wajib terdapat contoh penggunaan:

- Primitive types (`string`, `number`, `boolean`).
- Array.
- Interface.
- Type alias dan union type.
- Generics sederhana.

**5. Environment Variables**

- Menggunakan file `.env` untuk konfigurasi aplikasi.
- Membuat `.env.example`.
- Memastikan password dan API key rahasia tidak ditampilkan di website atau diunggah ke GitHub.
- Menggunakan contoh konfigurasi non-rahasia seperti nama aplikasi atau versi aplikasi.

### Pengumpulan Tugas

Mahasiswa wajib mengumpulkan:

1. **Link website pribadi** yang sudah menampilkan aplikasi tugas.
2. **Link repository GitHub** berisi source code dan riwayat commit.
3. **Screenshot** bukti branch, merge, Pull Request, dan penyelesaian conflict.
4. **Penjelasan singkat** di website pribadi mengenai penggunaan Git, npm, TypeScript, Vite, dan environment variables, termasuk peran compiler/transpiler/bundler.
